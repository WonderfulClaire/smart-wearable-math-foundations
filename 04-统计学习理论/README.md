# 04 统计学习理论

穿戴设备最常见的失败不是“训练集没学会”，而是换一个用户、换一种肤色、换一个佩戴松紧、换一台硬件后性能下降。统计学习理论帮助我们区分记忆与泛化，并建立可信的实验设计。

## 知识地图

| 知识点 | 工程问题 | 应用 |
|---|---|---|
| 经验风险与期望风险 | 离线平均损失能否代表真实用户？ | 训练目标、线上风险 |
| 假设空间与复杂度 | 模型越大是否一定越好？ | 模型选择、端侧部署 |
| 偏差—方差 | 欠拟合和过拟合怎样从数据上区分？ | 模型诊断、数据规划 |
| 正则化 | 怎样用先验约束模型？ | 权重衰减、数据增强 |
| 交叉验证 | 数据有限时怎样估计泛化误差？ | 超参数选择 |
| 数据泄漏 | 为什么随机切分会虚高？ | 跨用户、跨设备评测 |
| 分布偏移与 OOD | 新场景为何超出训练分布？ | 域适配、鲁棒性 |
| 校准与不确定性 | 置信度 0.9 真的有九成把握吗？ | 健康提醒、安全决策 |

## 工程主线：先定义“独立样本”

假设同一个用户连续佩戴设备 30 分钟，每秒产生一个窗口。如果把这些高度相似的窗口随机分到训练集和测试集，测试集就包含了训练用户、训练设备和相邻时间段的信息。模型看似泛化，实际上只是识别了用户或会话指纹。

可信切分应与最终应用一致：

- 要服务新用户：按用户分组切分。
- 要迁移到新设备：保留整台设备作为测试域。
- 要应对未来环境：按时间或场景切分。
- 要比较算法：固定数据切分，并报告置信区间和分组指标。

## 评测不能只报一个平均数

至少检查：

- 不同用户、设备、活动强度和噪声等级的分组性能；
- 平均值之外的方差、最差组与失败案例；
- 性能、延迟、功耗和模型大小；
- 概率输出的校准，而不只是分类准确率；
- 训练数据与测试数据是否存在重复片段或同源泄漏。

## 过关问题

1. 为什么一个用户的相邻时间窗口通常不是独立同分布样本？
2. 验证集和测试集分别承担什么职责？
3. 平均准确率相同的两个模型，为什么产品风险可能完全不同？
4. 数据增强、正则化和更小模型分别怎样改变偏差与方差？

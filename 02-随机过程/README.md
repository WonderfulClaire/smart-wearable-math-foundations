
# 02 随机过程

传感器输出不是一条确定曲线，而是“信号规律 + 随机扰动”的一次实现。随机过程帮助我们描述噪声怎样随时间变化、不同时间点怎样相关，以及能量怎样分布在频率上。

## 工程主线：PSD 不是一张“好看的频谱图”

对宽平稳过程 $x(t)$，自相关函数

$$
R_x(\tau)=\mathbb{E}[x(t)x^*(t-\tau)]
$$

只依赖时间差 $\tau$。功率谱密度是自相关函数的傅里叶变换：

$$
S_x(f)=\mathcal{F}\{R_x(\tau)\}.
$$

工程上我们只有有限长度的一段数据，所以 PSD 是估计量，而不是“真实答案”。窗口长度、重叠率、平均次数会在时间分辨率、频率分辨率与方差之间做取舍。

## 穿戴设备里的非平稳性

- 麦克风：从安静办公室走进地铁，噪声统计量突变。
- PPG：手臂运动改变光路，运动伪影会淹没心率成分。
- IMU：静止、步行、跑步对应不同动态模型。
- 耳机：摘戴和松紧变化会改变声学传递函数。

因此“局部平稳”通常比“全局平稳”更实用：在短窗口内估计统计量，并随时间更新。

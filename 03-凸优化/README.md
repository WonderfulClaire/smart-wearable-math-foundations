# 03 凸优化

工程算法不是“找一个公式”，而是在目标、约束和资源之间做选择。凸优化提供一种可解释的语言：我们到底在最小化什么，必须满足什么，以及什么时候可以相信得到的是全局最优解。

## 知识地图

| 知识点 | 工程问题 | 应用 |
|---|---|---|
| 凸集与凸函数 | 哪些问题没有坏的局部最优？ | 最小二乘、能量最小化 |
| 梯度与 Hessian | 参数变化会怎样影响误差？ | 标定、滤波、模型训练 |
| 拉格朗日乘子 | 怎样把硬约束加入目标函数？ | MVDR、权重和为 1 的融合 |
| KKT 条件 | 怎样验证一个约束解是否最优？ | 稀疏优化、资源分配 |
| 对偶问题 | 约束的“价格”是什么？ | 算力、延迟、功耗权衡 |
| L1/L2 正则化 | 数据不足时怎样限制不稳定解？ | 稀疏传感器选择、稳健标定 |
| 近端与投影方法 | 参数必须位于可行域时怎样更新？ | 概率权重、幅值和功率约束 |

## 工程主线：目标函数就是产品取舍

假设多个传感器都在估计同一物理量，融合结果为 $\hat y=w^Tx$。一个简单目标是

$$
\min_w \|Xw-y\|_2^2+\lambda\|w\|_2^2
\quad \text{s.t.}\quad \mathbf{1}^Tw=1.
$$

- 第一项要求拟合标定数据；
- 第二项抑制过大的权重，降低噪声放大与数值不稳定；
- 约束让融合权重保持可解释的尺度；
- $\lambda$ 不是纯数学常数，它代表“拟合历史数据”和“保持稳定”之间的产品选择。

## 为什么凸优化对非凸深度学习仍然有用

神经网络通常是非凸的，但损失函数设计、正则化、约束、学习率和局部二次近似仍然使用优化语言。更重要的是，很多穿戴算法会把神经网络和可解释模块组合：网络估计 mask 或噪声统计量，后端再解一个凸优化或闭式滤波问题。

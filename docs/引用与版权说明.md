
# 引用与版权说明

## 原创与引用边界

本项目的组织结构、工程案例、解释文字和数值实验以原创为原则。数学定义、经典定理和标准算法不可避免地依赖教材、论文和官方资料；使用这些内容时，应给出能够追溯到原始资料的引用。

以下内容必须标注来源：

- 非常规符号体系、定义或定理表述；
- 来自论文、教材或课程的图、表、数据和例题；
- 对已有代码的移植、翻译或实质性改写；
- 具体硬件参数、行业结论和实验数据；
- 不是常识且会影响工程决策的事实性结论。

## 不接受的做法

- 复制来源不明的博客、截图或“二手总结”；
- 只改写句式、不注明原始来源；
- 将论文中的实验结果写成项目自行验证的结论；
- 使用没有再分发权限的图片、数据或代码；
- 用生成式工具产生引用、DOI、实验数字或硬件参数后不核验。

## 推荐引用格式

正文中使用简短链接或编号引用，章节末尾列出完整信息。论文至少包含作者、题目、出版物、年份和 DOI/稳定链接；书籍至少包含作者、书名、版本、出版社和相关章节；网页应优先引用官方文档并注明访问日期。

示例：

```text
[1] S. Boyd and L. Vandenberghe, Convex Optimization,
    Cambridge University Press, 2004, Chapter 5.
```

## 图表与代码

- 优先重新绘制解释性图表，并在图注中注明“根据某来源改绘”；
- 引用第三方图片前确认许可证允许再分发；
- 改编第三方代码时，在文件头保留作者、来源、许可证和主要改动；
- 数值实验应固定随机种子并写明依赖、输入和运行命令。

## 事实核查责任

每位贡献者对其提交内容的准确性和版权合规负责。无论内容是否借助自动化或生成式工具完成，合入前都必须由贡献者核对公式、代码、引用和事实；项目不接受无法追溯来源的自动生成参考文献。
